# Contributing to SuperMarket ✨

First off, thank you for considering contributing to SuperMarket! It's people like you that make this open-source project such a great tool for the community.

## 🚀 Our Code of Conduct

Help us keep the environment friendly and welcoming for everyone:
*   Be respectful and patient with others.
*   Focus on constructive feedback.
*   Keep the conversation professional and on-topic.

## 🛠️ How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an **Issue** with:
1.  **A clear title** describing the problem.
2.  **Steps to reproduce** the issue.
3.  **Expected vs. Actual** results.
4.  **Screenshot/Video** if possible.

### Suggesting Enhancements
We're always looking for cool new features! Open an **Issue** and label it `enhancement`. Describe:
*   What is the feature?
*   Why is it needed?
*   How should it look/work?

### Pull Requests (PRs)
1.  Fork the repo and create your branch from `main`.
2.  Ensure your code follows the **Modern Next.js** standards.
3.  Ensure all your code is **TypeScript**-safe.
4.  Write clear, descriptive commit messages.
5.  Link your PR to an existing issue.

## 🎨 Styling Standards
*   Use **Vanilla CSS** with modern tokens for core components.
*   Use **TailwindCSS** for utility and layout spacing.
*   Ensure all components are **Responsive** (Mobile, Tablet, Desktop).

## 💡 Pro Tip
Check out the `lib/store.ts` for global state patterns before making changes to the data layer.

---

Happy coding! 🌌
